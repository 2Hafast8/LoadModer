Crash Diagnostics

Isolate crashing mods in 5 binary search steps.

Troubleshooting crashes by disabling mods one by one takes hours. LoadModer implements a binary search (bisect) routine that automatically divides candidate mods into test partitions until the root cause is isolated.

Binary Bisect: O(log N) — 5 game restarts

Dependency Graph

Recursive resolution prevents missing library errors.

Every install operation traverses a Directed Acyclic Graph (DAG) built from Modrinth metadata. Version constraints, loader targets, and secondary libraries are validated before any files are written to disk.

  • Version constraint validation per Minecraft release
  • Duplicate jar detection and clean replacement
  • Atomic file writing with rollback on network failure
